# FAB

Use the default FAB for the primary floating action.

```html
<button
  class="fab fab--default"
  type="button"
  aria-label="Open diagram fullscreen"
>
  <span aria-hidden="true">⛶</span>
</button>
```

```css
.fab--default {
  min-width: 56px;
  min-height: 56px;
  border-radius: var(--shape-large);
}
```
