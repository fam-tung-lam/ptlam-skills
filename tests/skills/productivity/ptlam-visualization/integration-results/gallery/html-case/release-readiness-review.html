Evidence and interpretation

Observed evidence

Two gate failures are confirmed

  • Checkout API errors reached 1.8% in the 60-minute canary, above the 0.5% release threshold.
  • The rollback rehearsal restored service in 18 minutes, missing the 10-minute recovery objective.
  • Core smoke tests, schema compatibility, and security scans passed.

Recommendation

Fix, rehearse, then re-run only affected gates

  1. Correct the retry fan-out introduced in rc3 and repeat the one-hour canary.
  2. Complete a timed rollback rehearsal with the on-call operator.
  3. Keep passed evidence valid unless the patch changes its owning surface.
Uncertainty: The checkout regression has a strong correlation with rc3 retry changes, but root cause is not yet proven. Treat that link as an inference, not evidence.
