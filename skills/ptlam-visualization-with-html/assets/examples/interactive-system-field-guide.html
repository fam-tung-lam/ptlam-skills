Step 02 · Memory cadence

Layered by how often it changes

The real mapping is lifetime and role. Each everyday layer sits beside the literal layer with the same cadence.

Everyday · hotel desk

Stable · weeksHotel policies and service directoryRebuilt when policy or approved vendors change.
Context · daysGuest and reservation notesExpires when the stay ends.
Volatile · one shiftOpen requests and live handoff stateChanges with every interaction.

Literal · software agent

Stable · weeksIdentity, rules, and tool guidanceRebuilt when instructions or tools change.
Context · daysProject and discovered contextRefreshed when the working scope changes.
Volatile · one sessionCurrent messages and live stateChanges during the active conversation.
