# Platform adaptation

Use the portable HTML baseline for pointer, keyboard, touch, and assistive
technology. When the target is a watch-sized or spatial/XR surface, read the
corresponding official foundation guidance and adapt layout, reach, depth,
input, and component availability before reusing a desktop pattern.

- [Material for watches](https://m3.material.io/foundations/watches/overview)
- [Material for XR](https://m3.material.io/foundations/xr/design/overview)

Do not claim a platform-specific Material component is implemented on the web
merely because its visual appearance can be reproduced in HTML.
