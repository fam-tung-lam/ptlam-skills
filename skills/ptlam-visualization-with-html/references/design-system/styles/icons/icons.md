# Icons

Use simple, recognizable symbols with a consistent optical size, stroke or fill
treatment, and baseline. Pair unfamiliar icons with visible text. Every
icon-only button needs an accessible name; decorative icons are hidden from
assistive technology.

Icons in this expressive system use clear filled or outlined contrast plus shape
or rotation changes to explain state, such as a split-button menu opening.
Preserve the same end state under reduced motion. Follow Material's
[icon overview](https://m3.material.io/styles/icons/overview) and
[applying-icons guidance](https://m3.material.io/styles/icons/applying-icons).
