# Spacing tokens

The scaffold owns the exact baseline values. Use the shared spacing scale to
express grouping, hierarchy, and touch safety; keep related controls closer
than unrelated regions and preserve whitespace around the current learning
focus.

Use the smallest spacing step that preserves grouping and touch-target size. Do
not introduce one-off gaps or shrink targets to fit more content. Reflow first.

Source: Material's
[spacing tokens](https://m3.material.io/styles/spacing/tokens).
