# Filled icon button

Use for the highest-emphasis icon-only action in a local group.

```html
<button class="icon-button icon-button--filled" type="button" aria-label="Play">
  <span aria-hidden="true">▶</span>
</button>
```

```css
.icon-button--filled {
  background: var(--color-primary);
  color: var(--color-on-primary);
}
```
