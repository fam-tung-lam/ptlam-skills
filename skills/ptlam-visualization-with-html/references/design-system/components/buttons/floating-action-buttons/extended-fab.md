# Extended FAB

Use when the floating action needs both an icon and a short visible label.

```html
<button class="fab fab--extended" type="button">
  <span aria-hidden="true">⛶</span> Fullscreen
</button>
```

```css
.fab--extended {
  min-height: 56px;
  gap: var(--space-2);
  padding-inline: var(--space-4);
  border-radius: var(--shape-large);
}
```
