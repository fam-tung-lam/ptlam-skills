# Themes and layouts

Authority: `packages/mermaid/src/docs/config/theming.md`,
`packages/mermaid/src/docs/config/layouts.md`, and
`packages/mermaid/src/docs/syntax/architecture.md` at `mermaid@11.16.0`.

Use built-in themes and schema-approved variables. Prefer the stable default
layout unless another pinned layout materially improves comprehension. The
capsule pins ELK and tidy-tree because Mermaid CLI registers them separately.

Use the classic look by default. Hand-drawn output and Architecture boundary
waviness have seeds; set non-random values when selected. Layout choice and seed
belong in rendering evidence because they affect visual reproducibility.
