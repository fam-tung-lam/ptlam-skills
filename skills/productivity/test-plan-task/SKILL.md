# Plan a Task

Convert the user's goal into an ordered plan of 3–5 steps.

## Workflow

1. Restate the goal in one concise sentence.
2. Identify the smallest sequence of concrete actions that reaches the goal.
3. Write 3–5 numbered steps, starting each step with an action verb.
4. Add a verifiable `Done when:` condition to every step.
5. State any necessary assumption briefly; do not invent optional work.

Keep the plan specific enough to execute immediately and small enough to scan
quickly.
