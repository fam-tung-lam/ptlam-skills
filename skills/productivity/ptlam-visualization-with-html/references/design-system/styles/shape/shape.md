# Shape

Read [shape tokens](../../tokens/shape.md). Apply consistent shape roles:

- small for compact labels and state values;
- medium for buttons and controls;
- large for panels and diagram stages;
- full for circular icon buttons and pills.

Use a different shape only when it distinguishes family, state, or containment.

M3 Expressive may use contrasting shapes and shape morphs for selection,
expansion, and progress. Preserve readable silhouettes and a non-motion state
cue. See Material's
[shape principles](https://m3.material.io/styles/shape/overview-principles) and
[shape morph](https://m3.material.io/styles/shape/shape-morph).
