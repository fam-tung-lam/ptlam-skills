# Spacing

Read [spacing tokens](../../tokens/spacing.md). Use spacing to reveal grouping,
hierarchy, and touch safety. Keep related controls closer than unrelated regions
and preserve whitespace around the current learning focus.

Do not reduce spacing below usable target sizes to fit more content. Reflow the
layout first. See Material's
[spacing overview](https://m3.material.io/styles/spacing/overview) and
[applying-spacing guidance](https://m3.material.io/styles/spacing/applying-spacing).
