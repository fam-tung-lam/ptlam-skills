# Shape tokens

```css
:root {
  --shape-none: 0;
  --shape-extra-small: 0.25rem;
  --shape-small: 0.5rem;
  --shape-medium: 0.75rem;
  --shape-large: 1rem;
  --shape-extra-large: 1.75rem;
  --shape-full: 999rem;
  --shape-expressive-soft: 1.5rem 0.75rem 1.5rem 0.75rem;
  --shape-expressive-active: 0.75rem 1.5rem 0.75rem 1.5rem;
}
```

Use shape to clarify containment and component family. Do not vary radius only
for decoration.

M3 Expressive expands the available shape library and supports shape morphing.
Keep start and end shapes semantically related and compatible with reduced
motion. See Material's
[corner-radius scale](https://m3.material.io/styles/shape/corner-radius-scale)
and [shape morph](https://m3.material.io/styles/shape/shape-morph).
