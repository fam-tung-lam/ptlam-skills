# Tokens

Tokens are the portable CSS interface for this design system. They follow
Material 3's semantic system-role approach and include the expressive shape,
motion, and type dimensions needed by M3 Expressive.

- [Color](color.md)
- [Typography](typography.md)
- [Spacing](spacing.md)
- [Shape](shape.md)
- [Elevation](elevation.md)
- [Motion](motion.md)
- [State](state.md)

Copy only the groups consumed by the selected styles and components into one
`:root` block. Change values for an explicit subject design system without
renaming the semantic roles. Components must not consume raw palette values.

Source: Material's
[design-token overview](https://m3.material.io/foundations/design-tokens/overview).
