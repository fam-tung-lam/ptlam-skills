# Tokens

Tokens are the portable CSS interface for this design system. Copy the token
groups required by the selected styles and components into one `:root` block:

- [Color](color.md)
- [Typography](typography.md)
- [Spacing](spacing.md)
- [Shape](shape.md)
- [Elevation](elevation.md)

Use semantic names. Change values for an explicit subject design system without
renaming the semantic contract consumed by components and patterns.
