# Spacing tokens

```css
:root {
  --content-max: 76rem;
  --space-0: 0;
  --space-1: 0.375rem;
  --space-2: 0.625rem;
  --space-3: 1rem;
  --space-4: 1.5rem;
  --space-5: 2.25rem;
  --space-6: 3rem;
  --space-7: 4rem;
}
```

Use the smallest spacing step that preserves grouping and touch-target size. Do
not introduce one-off gaps when a token expresses the same relationship.

Source: Material's
[spacing tokens](https://m3.material.io/styles/spacing/tokens).
