# Usability and M3 Expressive

Use M3 Expressive to improve comprehension, hierarchy, and emotional clarity.
Combine a restrained set of vibrant role colors, contrasting shapes, flexible
type, and motion physics around the current task.

- Give the primary action or current state the strongest visual voice.
- Use shape changes to clarify selection, expansion, or progress.
- Use motion to preserve spatial continuity and show cause and effect.
- Keep expressive movement interruptible and fully reduced by user preference.
- Keep familiar component anatomy and predictable interaction behavior.
- Test whether emphasis helps people find, understand, and complete the task.

Expressiveness is not maximal decoration. Preserve usability, accessibility, and
cross-platform adaptation. Use the current Material 3
[usability guidance](https://m3.material.io/foundations/usability/overview) and
[M3 Expressive overview](https://m3.material.io/blog/building-with-m3-expressive)
as governing sources.
