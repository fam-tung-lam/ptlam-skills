# Diagrams

Diagrams are reusable visual components that expose structure, relationships, or
transitions. Choose the smallest family that teaches the mechanism:

- [Flowchart](flowchart.md)
- [C4 semantic-zoom diagram](c4-diagram.md)
- [State diagram](state-diagram.md)
- [Interactive sequence diagram](sequence-diagram.md)
- [Entity-relationship diagram](erd.md)
- [Synchronized analogy twin](analogy-twin.md)

Every diagram component must scale from one SVG `viewBox`, expose a non-empty
accessible name, keep labels clear of nodes and edges, show direction visibly,
and remain composable with adjacent state or controls.

For case-specific assemblies, use the
[interactive flow patterns](../../patterns/interactive-flows/interactive-flows.md).
