# Filled tonal icon button

Use for a medium-emphasis icon action with a quiet container.

```html
<button class="icon-button icon-button--tonal" type="button" aria-label="Pause">
  <span aria-hidden="true">Ⅱ</span>
</button>
```

```css
.icon-button--tonal {
  background: var(--color-primary-container);
}
```
