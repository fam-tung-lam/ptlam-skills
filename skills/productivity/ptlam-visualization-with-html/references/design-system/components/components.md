# Components

Components are reusable UI primitives with standard family and variant names.
Current families:

- [Buttons](buttons/buttons.md)
- [Icon buttons](icon-buttons/icon-buttons.md)
- [Floating action buttons](floating-action-buttons/floating-action-buttons.md)

Keep artifact-specific combinations out of this catalog. Compose components into
a learning behavior under [patterns](../patterns/patterns.md).
