# Patterns

Patterns compose foundations, styles, and components into a reusable learning
behavior. They may name a teaching structure, but must not redefine a base
component family.

Every pattern inherits the one expressive system. Use containment, scale, shape,
color, and synchronized motion to make the current concept and its relationships
immediately findable. A quieter context changes expressive intensity; it does
not switch to a non-expressive pattern.
